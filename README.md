## Gallery

Pictures are the **gallery** folder in the file list, beside the category folders. Filenames, alt text, and captions live in `_data/gallery.yml`. Set `gallery_base_url` in `_config.yml` to a public Cloudflare R2 address such as `https://photos.gleebsal.net`. Leave it blank to keep using the local placeholders in `assets/img/gallery/`.

Do not commit API tokens or rclone config. Setup steps: [docs/gallery-r2.md](docs/gallery-r2.md).
